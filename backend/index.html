API Endpoint Tester

Доступные API endpoints

Для GET и DELETE укажи параметры в поле ниже как JSON. Для POST и PUT это поле отправляется как JSON body.

GET    /category
        без параметров — все категории
        {"id": 1} — категория по id

POST   /category
        {"name": "BMW"}

PUT    /category
        {"id": 1, "name": "Audi"}

DELETE /category
        {"id": 1}

GET    /article
        без параметров — все статьи
        {"id": 1} — статья по id
        {"category_id": 1} — статьи категории

POST   /article
        {"title": "BMW M5", "content": "Описание", "category_id": 1}

PUT    /article
        {"id": 1, "title": "BMW M5", "content": "Новое описание", "category_id": 1}

DELETE /article
        {"id": 1}
